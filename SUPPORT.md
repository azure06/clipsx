# Getting help with ClipsX

Start with the [README](README.md), the selected release's
[notes](https://github.com/azure06/clipsx/releases), and the
[existing issues](https://github.com/azure06/clipsx/issues). Release notes describe
the verified platforms and limitations for that version.

## Bugs, feature ideas, and questions

Use the [issue chooser](https://github.com/azure06/clipsx/issues/new/choose):

- **Bug report:** something behaves incorrectly. Include the app version,
  operating system, and steps to reproduce with harmless sample data.
- **Feature request:** explain the workflow problem, the outcome you want, and
  alternatives you have tried. Discuss substantial changes before implementing them.
- **Question or help:** ask about installation, configuration, or using the app.

For an extension-specific problem, include its package ID and version. Identify
whether the problem occurs without that extension when you can safely check.
For code or documentation contributions, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Keep sensitive information private

Public issues and their attachments are visible to everyone. Use synthetic
clipboard content and redact secrets, personal information, file paths, account
details, and unrelated history from logs or screenshots. Do not upload your
clipboard database, API keys, tokens, or entire diagnostic folders.

- Report vulnerabilities using the private channels in [SECURITY.md](SECURITY.md).
- Report harassment or other conduct concerns using the private contact in the
  [Code of Conduct](CODE_OF_CONDUCT.md).
- For other questions requiring private details, email
  [support@clipsx.app](mailto:support@clipsx.app). Send only the minimum information needed.

ClipsX is independently maintained. Support is provided as time permits, without
a guaranteed response time. Sponsorship supports maintenance and does not
include priority support or a service-level agreement.
