# ClipsX 0.1.9

- Add zoom, pan, Fit, 100% and expanded viewing for image previews. Open a separate full-resolution copy in the default image app without changing the stored clip.
- Support trackpad pinch in visual previews while keeping the rest of the app at its normal size. Custom extension previews can expand without restarting their view.
- Give synced devices recognizable computer names and Rename/Remove controls. Removing a device stops its sync access, clears its list entry and frees a device slot without deleting local or cloud settings.
- Show privacy decision progress and distinguish unchecked clips from content marked private. Preserve long copied text during capture.
- Apply model context limits consistently in Recall.
- Update request and validation dependencies to patched versions.

Device management requires the matching configuration-sync backend update. Diagram canvas navigation is supplied by the installed extension. No database reset is required. The updater public key and stable endpoint are unchanged.
