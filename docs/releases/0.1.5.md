# ClipsX 0.1.5

- Add an agentic Recall workspace with saved local conversations, clipboard sources, image context, and undoable actions.
- Configure multiple Ollama, OpenAI, Anthropic, Gemini, and OpenRouter connections and assign models independently to supported features.
- Add authenticated local MCP access to shared clipboard tools for compatible external assistants.
- Improve context budgeting, conversation compaction, capability handling, and provider diagnostics.
- Preserve the active semantic index while a replacement embedding configuration builds.

Existing supported databases upgrade through forward migrations without a reset. Saved conversations remain local and independent of clipboard retention. Hosted indexing requires explicit enablement; MCP is disabled by default and requires client grants.

Provider and model capabilities vary. Automated provider fixtures verify the native transport; they do not certify every live model or external assistant. Installed platform and updater certification is required before publication. The updater public key and stable update endpoint are unchanged.
