# ClipsX 0.1.16

- Choose a 1-, 2-, or 5-minute embedding timeout in **Intelligence → Indexing → Advanced indexing settings**. The default is 2 minutes and applies to Ollama and hosted embedding providers.
- See which clips timed out and retry them while keeping completed work. **Index missing** can resume a failed first build. During a replacement, Meaning Search can keep using the previous index.
- History and Recall show keyword matches while Meaning Search runs in the background. Changing the query cancels the previous Meaning Search request.
