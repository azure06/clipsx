# ClipsX 0.1.10

- Find tags in a searchable picker beside All, Favorites and Pinned. Combine a tag filter with the current view and text search.
- Show readable tag names on history rows and editable tag chips above the clip preview, with improved spacing and light/dark styling.
- Show tags created by decision rules immediately, including when the capture is outside the current view. Refreshing the tag list preserves newly received tags.
- Search existing tags or create a new one from the preview. Confirm before deleting a tag from all clips; removing a preview chip affects only that clip.
