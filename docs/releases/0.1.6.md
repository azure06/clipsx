# ClipsX 0.1.6

- Update Wasmtime to 48.0.6 and rustls to 0.23.46 for dependency security fixes.
- Add Settings → About with version, build identity, copyable app information, and update controls.
- Improve assistant integration layouts, simplify Codex token setup, and allow deleting active or revoked assistant access.
- Guide MCP assistants to retrieve relevant saved context, use meaning-based search for vague memories, and inspect sources before answering.
- Include initial clipboard evidence in Recall, fit evidence to the remaining model context, and consolidate chat controls.
- Add platform-specific shortcut defaults, support disabling the global shortcut, and show shortcut conflicts.
- Restore macOS Dock activation and stabilize indexing status.
- Reduce false secret detection by requiring evidence of credentials rather than entropy alone.

These updates preserve supported databases without a reset. Deleting assistant access disconnects its sessions while retaining clips and activity. MCP remains disabled by default; meaning-based retrieval requires a configured embedding model. Provider credentials remain in protected device-local storage.

The updater public key and stable update endpoint are unchanged. Installed platform and updater certification is required before publication; source tests do not establish installed-artifact compatibility or guarantee that every external model follows MCP guidance.
