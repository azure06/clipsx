# ClipsX 0.1.11

- Keep frequent clips in a compact pinned section. Reorder them from the full Pinned view; the order survives restart.
- Separate Preview and Results, with a View menu and Details inspector for alternate views and stored formats.
- Run compatible transformation setups directly from the preview. Browse results, compare with the original, and copy the selected output.
- Manage saved preview defaults in Settings, including resetting individual choices. Table defaults take precedence over HTML defaults for Excel captures.
- Move tags into a compact preview footer and keep privacy-check details at the bottom.
- Preserve completed OCR and pending search updates across restart. Fix image/OCR switching getting stuck loading.
- Remove an incorrect Secret classification with Not a secret. Later detection may classify it again; separate Private restrictions remain.
- Save the detected-secret exclusion switch immediately. Decision models prefer plain text, with extracted HTML/RTF text as fallback; native secret detection still checks every text representation.
- Copy selected text from host previews as plain text without HTML. Explicit Copy actions and extension webviews keep their existing behavior.

- Update the extension compilation cache to patched compression dependencies while retaining persistent caching.

Existing clipboard data and settings are preserved during the supported upgrade. No database reset or extension update is required.
