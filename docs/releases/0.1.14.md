- Each applicable capture automation rule runs independently. Clip details show skipped and failed attempts, linked results, and a retry action when available.
- Detected secrets are masked in history. Copy still uses the original clipboard content.
- The model assignments editor uses **Done** to close editing after changes save automatically.
- Updated the bundled SQLite library and MCP SDK to address dependency advisories.
