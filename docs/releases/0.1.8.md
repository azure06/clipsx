# ClipsX 0.1.8

- Add optional privacy and General decisions models. Keep built-in secret detection active and let rules tag, favorite, pin, mark private, or exclude matching copies before storage.
- Make Intelligence Overview the first page, with model assignments, search progress, and setup shortcuts.
- Let permitted extensions request General decisions through Extension API 3.3, retaining compatibility with existing 3.2 packages.
- Add multiple ordered automation rules per application, optional decision conditions, sample testing, and retryable failures. Only the first matching Rewrite setup runs; results remain attached to the original.
- Update Wasmtime and certificate-verification dependencies to patched versions.

Models can run locally or use an explicitly selected hosted provider. Local models are recommended for privacy checks. No database reset is required. The updater public key and stable endpoint are unchanged.
