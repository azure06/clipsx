# ClipsX 0.1.7

- Give shortcut recorders keyboard focus when recording starts, so clicks can capture new global, extension, and built-in command shortcuts on WebKit.
- Remember the normal window size across restarts, centered and fitted to the available screen. Window position and maximized/fullscreen state are not restored.

- Update extension archive handling to the patched ZIP library and disable unused ZIP updater payloads while retaining the published installer formats.

No database reset is required. The updater public key and stable update endpoint are unchanged.
