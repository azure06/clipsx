# ClipsX 0.1.0

ClipsX provides local clipboard history, text and optional semantic search,
local OCR, configuration sync, and programmable Extension API v3.2 operations.

## Installation and updates

Packages target Windows x64, macOS Apple Silicon and Intel, and Linux/X11 x64.
Windows uses a signed NSIS installer. macOS packages use Developer ID signing,
notarization and stapling. Linux downloads include AppImage and Debian packages.
In-app updates verify the retained Tauri signing key and select the matching
installer format and architecture.

## Data and compatibility

The database baseline is version 15. Installations using an incompatible older
schema require an explicit reset; there is no compatibility migration for that
baseline. Back up needed clipboard content before resetting. Configuration sync
does not synchronize clipboard contents.

## Platform limits and recovery

Linux certification covers X11; Wayland is outside this release's platform claims.
An interrupted or failed update can be recovered by installing the signed package
for the same or a newer version from this release. Automatic downgrade and
rollback are not provided. Installed-platform evidence remains attached to the
release certification record.
